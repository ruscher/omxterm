# UX/UI design system

Windows uses the shared theme and Settings system plus app-drawn window chrome.
Shell discovery is exposed as a native HTML datalist attached to the existing
editable field. This preserves keyboard entry, custom paths and form semantics;
when a saved profile is active that field becomes read-only and the Config File
page edits its structure. A graphical profile manager is not implemented.

The open Settings dialog remains localized in English and Brazilian Portuguese,
modal, keyboard reachable and validated through main. High contrast, screen
reader behavior, reduced motion, 100–200% DPI, mixed-monitor DPI and the visual
quality of shell suggestions require native Windows observation. No Fluent,
Mica or pixel-parity claim is made from Linux rendering.
